# Teorth Notes for Stage 2 Solver Routes

Updated: 2026-05-19

This file is the theory-facing index for solver-route provenance. It complements `stage2/docs/solver-route-ledger.md` and the route motif cards under `stage2/docs/motif-cards/`.

## Boundary

Teorth data guides solver design and proof motifs. The submitted solver must not read Teorth caches, scrape live pages, import Teorth theorem names, or depend on repo-local data at runtime. The official Lean judge remains the acceptance source.

## Motif Extraction Workflow

1. Start from a failed or not-attempted Stage 2 row.
2. Map `eq1_id` and `eq2_id` to equation text from `data/exports/equations.txt`.
3. Check `graph.json` and `full_entries.json` for proof or false-witness provenance.
4. If a proof page exists, classify each step as direct substitution, projection rewrite, bounded closure, theorem-chain gap, or unsupported motif.
5. If a finite witness hint exists, test named/structured/affine/quadratic families locally before adding a table.
6. Distill only reusable triggers into solver code or motif cards.
7. Validate every emitted certificate through the official runner before promotion.
