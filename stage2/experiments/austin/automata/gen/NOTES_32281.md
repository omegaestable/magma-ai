### `RS` IS NOW PROVED — no fuel induction is needed anywhere

The result-size bound
```lean
theorem RS (u v : M) : op u v = J u v ∨ sz (op u v) < sz v
```
was expected to need a `msr`-fuel strong induction (the recursive rule's result is `op u q`, not a
subterm of `v`). **It does not.** The R3 disjunct of `TR` carries a *second* gate,
`msr u (op (op (op u q) (a2 v)) (a2 v)) < msr u v`, and `mx` turns it into `sz X <= sz v` for
`X = op (op r w) w`, `r = op u v`, `w = a2 v` (using `SU`'s `sz u < sz v`). Then two `by_cases` on
freeness finish it:
* `op r w` decoded => `SU` gives `sz r < sz w < sz v` — done;
* `op r w` free and `op (J r w) w` decoded => `SU` gives `sz (J r w) < sz w`, i.e.
  `sz r + sz w + 1 < sz w` — impossible;
* both free => `X = J (J r w) w`, so `sz r + 2*sz w + 2 = sz X <= sz v` — done.

That is the generalisable trick for this family: **a recursive rule's gate bounds its own result**;
read the gate with `mx` before reaching for PLAYBOOK_PROOF §4's `CMP`/fuel machinery.

### The counterexample in words

Write `enc R u W = J (J u (J (J R W) W)) W` (the R1 encoding: `op u (enc R u W) = R`).
Take **`Q0 = enc r z w`** — an encoding whose *payload* is `r` and whose *decoder* is `z` — and then

* `x  := Q0`
* `y  := enc Q0 Q0 v`  — an encoding whose **payload equals its decoder**, and both are `Q0`
* `z  := z`

Then `op x y = Q0` (R1: `a1 (a1 y) = Q0 = x`, payload `Q0`), so `P = Q0`; and
`Q = op P y = op Q0 y = Q0` for the same reason; so `A = op z Q = op z Q0 = r` — **decoded, not free**.
Concretely with `z,r,w,v = g0,g1,g2,g3`: `x = ((g0*((g1*g2)*g2))*g2)`,
