## The construction, stated before any measurement

Every model in this family is a term algebra `M ::= g n | J a b | E a b | ...` with `op` a rule system
over it. The law quantifies over **all of `M`**, so the adversary may instantiate `x`,`y`,`z` at terms
that *look* like the model's own outputs but were never produced by `op`. That is the forgery.

**The subalgebra generated by the generators is not all of `M`.** `op` produces
`E u v` only when its free branch fires, `D2 p v` only when the mark fires, and a bare payload
otherwise; so every `E a b` with a rule firing at `(a,b)`, and every `J a b` at all (nothing emits `J`),
is in the term algebra and **not in the image of the evaluation map**.

> **Take the carrier to be that image.** Satisfaction of an equation is inherited by subalgebras
> (downward), so restricting can only remove failures; and every guard is anchored for free, because a
> node of the model's own shape in the image *provably came from the rule that emits it*.

### Lean encoding (decided before measuring, because it constrains the design)

Not a subtype. **A quotient of the free magma**, which is strictly better because it hands the proof a
structural induction on the *derivation*:

```lean
inductive W | gg : Nat -> W | mm : W -> W -> W        -- the free magma on the generators
def ev : W -> M                                       -- ev (gg n) = g n ; ev (mm a b) = op (ev a) (ev b)
def C := Quot (fun a b : W => ev a = ev b)
instance : Magma C := <Quot.lift2 (fun a b => Quot.mk _ (W.mm a b)) ...>
```

* the lift is well defined by `congrArg2 op` — one line, no side conditions;
* `Quot.ind` x3 reduces `EquationLHS C` to
  `forall a b c : W, ev a = op (ev b) (op (op (ev a) (op (ev b) (ev a))) (op (ev c) (ev b)))`,
  i.e. **the law restricted to the image, with a W-term witness for each variable**;
* `Quot.sound` closes it, and `Quot.sound` is an allowed axiom (CLAUDE.md judge statuses);
* `!=` for the eq2 refutation goes through `val := Quot.lift ev (fun _ _ h => h)` and `congrArg val`.

**No identity is needed anywhere**, so the `PLAYBOOK_QUOTIENT.md` objection ("every quotient design starts
from a derived identity, and 11081/12087 force none") does not apply: this quotient is by
*equality of value in M*, which is a congruence by construction, not by a derived law.

### THE IMAGE THEOREM — why this was inevitable, and what it costs

> **Let `M` be a term model with operation `op` and generators `X`. The smallest sub-magma of `M`
> containing `X` is `Im(ev)`, the image of the free magma on `X`. Any carrier that (a) keeps `op`
> unchanged and (b) is a magma containing `X` contains `Im(ev)`. Therefore a failing instance whose
> `x`, `y`, `z` are each `op`-built from generators survives EVERY carrier restriction.**

Proof: a magma is closed under its operation, so a sub-magma containing `X` contains `ev(w)` for every
free-magma term `w`, by induction on `w`. The law is universally quantified, so any triple in the
sub-magma is an instance. QED.

**Consequence, and it is the useful half.** "Restrict the carrier to the terms the model itself builds"
is exactly `Im(ev)` — it is *forced*, there is no smaller choice, and it is **void against any failure
whose witness is `op`-built**. So the escape as stated cannot, on its own, close a cell whose witness the
model constructs itself. It can only delete failures whose witnesses are **forged** — terms of the
model's own shape that `op` never emits.

> **Restatement of the target, which is what the four proofs were actually asking for:
> the image restriction does not remove FAILURES, it removes OBLIGATIONS.**
> A rule that was rejected because it misfires at a forged `(u,v)` is admissible on the image. So the
> anchored carrier is not a repair of a rule set — it is a *licence* to re-admit rules the free carrier
> vetoed. The design loop is therefore: re-rank every rejected rule set on the image and keep the ones
> whose only regressions were at forged pairs.

**And the sharp test for any law is one question**: *is the residual failure's witness `op`-built?*
* op-built  ⇒ the image is void for that law; only a change to `op` (or a quotient, which changes `op`)
  can help.
* forged    ⇒ the image deletes the cell for free.

11081 v20: **op-built.** The image is void for it. Recorded so no one repeats the measurement.
