**MAIN (the one general lemma, W3-7).** If `B` is free (`op y (op y x) = J y (op y x)`) and `C` is free

with `u = J (J y (op y x)) x` the guard reads `a = y`, `b = op y x`, `q = x`, so
`r1 = op y x = b` is **`rfl`** and `r2 = op y (op y x) = J y b` is exactly the freeness of `B`.
Result `a2 u = x`.   ⇒ `exact RD rfl rfl rfl hB`.

Leaves:
1. `x ≠ K`, `y ≠ x` — `A = J y x`, `B = J y A`, `C = J B x`, all three by `FR` (size). MAIN.
2. `x ≠ K`, `y = x`, `op x K = J x K` — `A = K`, `B = J x K`, `C = J B x`. MAIN (with `y := x`).
3. `x ≠ K`, `y = x`, `op x K = a2 x` (so `tg x = 2`) — `C = J (a2 x) x`, and **D2** fires:
   `tg (a2 C) = tg x = 2`, `a2 (a2 C) = a2 x = a1 C`. Result `a2 C = x`.
4. `x = K`:
   * `op y K = K` ⇒ everything collapses: `simp only [hA, sq]`.
   * `op y K = A ≠ K` ⇒ `y ≠ A` (TR + size), `B = J y A` by `FR`, and `C = op B K` is **free** —
     that is the only real work, lemma `NOFK`. Then MAIN with `x := K`.

**Refuting D and D2 on `(B, K)` with `B = J y A`, `A = op y K ≠ K`** (this is leaf 4's content).

* `y = K` ⇒ `A = op K K = K`, contradiction.
* `A = a2 y` (`tg y = 2`): D needs `op (a1 y) A = a2 y` **and** `op (a1 y) (a2 y) = J (a1 y) (a2 y)`;

  D2 needs `a2 A = K = y`, then `A = op K K = K`, contradiction. ✗
