### How the three rules were derived (each from a failing family, mechanically)

* **R2 DEC** is the generic decode: the code of `x` under `z` is `c = op(op(x, op(z,x)), E)`, which is
  free `((x * q) * E)` with `q = op(z,x)`; reading it needs `<u,a> = b`.
* **R3 SELFE** is the `x = E` branch. `code_E(z) = op(op(E, op(z,E)), E)`; when `z = (w * op(E,w))` the
  middle product `op(E, (z*E))` DEC-fires and returns `w`, so the code degenerates to `(w * E)` and
  `op(z, (w*E)) = E` has to be a rule.  This is exactly the free-model coincidence that refuted the free
  carrier (`x` a square = `E`, `z = (w * (x*w))`), now made a definition.
* **The `not (a = E and b = E)` guard on R2 is forced** by the junk element `K = (E*E)`.
  Without it, `x=E, z=K` needs `op(K,E) = E` while `x=z=K` needs `op(K,E) = (K*E)` — a genuine conflict
  on the same pair.  With the guard both work, and the guard is **free**: `w = (a*b)` in a real code is
  `op(x, op(z,x))`, and `w = (E*E)` would need `op(x,op(z,x))` to be the *free* product `(E*E)`, i.e.
  `x = E` and `op(z,E) = E`; but `op(z,E) = E` only via R1 (`z = E`), and then `op(E,E) = E != (E*E)`.
  So `(E*E)` is never a real code body.  (Two intermediate variants — `b != E` plus a separate
  `SELF2` rule, and a `JEE` rule `op ((E*E)) E = E` — were tried and each broke another family; the
  history is in this file's git blame.)

## The Lean certificate — `gen/q34889_a.lean`, compiles clean, 10,182 B

```lean
def P1 (u v) := tg v = 2 ∧ a2 v = E ∧ tg (a1 v) = 2 ∧ ¬(a1 (a1 v) = E ∧ a2 (a1 v) = E)
def P2 (u v) := tg v = 2 ∧ a2 v = E ∧ tg u = 2 ∧ a1 u = a1 v
def op (u v) :=
  let p1 := if hs1 : msr u (a1 (a1 v)) < msr u v then op u (a1 (a1 v)) else J u v
  let p2 := if hs2 : msr E (a1 v)       < msr u v then op E (a1 v)       else J u v
  if u = v then E
  else if P1 u v ∧ msr u (a1 (a1 v)) < msr u v ∧ a2 (a1 v) = p1 then a1 (a1 v)
  else if P2 u v ∧ msr E (a1 v)      < msr u v ∧ a2 u = p2       then E

```

### The lemma structure that worked (this is the reusable part)

| lemma | statement |
| --- | --- |
| `msr_lt` | `max (sz a) (sz b) ≤ max (sz u) (sz v) → sz a + sz b < sz u + sz v → msr a b < msr u v` — one lemma replaces the two `msr_lt_of_max_lt/eq` of the generated skeletons; proof is `unfold msr; have := Nat.mul_le_mul h h; omega` |
| `op_cases` | the standard 2-let packing, `⟨_, _, rfl, rfl, op.eq_1 u v⟩` |
| `TR` | 4-way digest: `op u v = J u v ∨ (u = v ∧ op u v = E) ∨ (P1 ∧ a2 (a1 v) = op u (a1 (a1 v)) ∧ op u v = a1 (a1 v)) ∨ (P2 ∧ a2 u = op E (a1 v) ∧ op u v = E)` |
| `SQ u` | `op u u = E` (`rw [hop]; simp`) |
| `WF` | `¬(tg v = 2 ∧ a2 v = E) → u ≠ v → op u v = J u v` — **both rules share `tg v = 2 ∧ a2 v = E`**, so ONE lemma frees every product whose right argument is not `(_ * E)` |
| `opEw` | `op E w = E → w = E` |
| **`FD`** | **the general freeness invariant (W3-7): `∀ n u a, sz a ≤ n → sz a < sz (a1 u) → op u a = J u a`** — fuel induction; kills R1 by size, SELFE because it needs `a1 u = a1 a` while `sz (a1 a) < sz a < sz (a1 u)`, and DEC by the IH (`b' = J u a'` is bigger than `u`, but `b'` sits inside `a`) |
| `G1`,`G2` | the two gates hold unconditionally under the rules' `tg` conditions |
| `ROOT` | `¬(a = E ∧ b = E) → b = op z a → op z (J (J a b) E) = a` (self-contained: `z = J (J a b) E` is refuted by `FD`) |
| `ROOT2` | `tg z = 2 → a2 z = op E (a1 z) → ¬(a1 z = E ∧ a2 z = E) → op z (J (a1 z) E) = E` — DEC is blocked before SELFE by `FD` again |
| `FREEP` | `x ≠ E → op x (op z x) = J x (op z x)` (3 cases of `TR z x`; the DEC case is `FD`) |
| `law` | `rw [SQ y]`, `by_cases x = E`; generic: `rw [FREEP, WF]; exact ROOT ..`; `x = E`: `by_cases z = E` (`simp only [SQ]`), else `rw [WF]` and `rcases TR E (J z E)` -> free branch `ROOT`, DEC branch `ROOT2` |
