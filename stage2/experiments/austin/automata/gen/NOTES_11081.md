### The three remaining goals (exact)

**(1) `Dfree (x y z) : op (J x (op y x)) (op z y) = J (J x (op y x)) (op z y)`** — the 4th chain
product must be free. Write `B = J x A`, `A = op y x`, `C = op z y`. Assume it decodes; `TR` gives
`tg C = 2`, `tg (a1 C) = 2`, `a2 (a1 C) = op B (a1 (a1 C))`, `CK B (a2 C)`. Hand analysis (not yet in
Lean):
* `CK` disjunct 1 (`tg (a2 C) = 2 ∧ B = a2 (a2 C)`): **refutable by size in all four A/C cases** —
  A free makes `sz B = 2 sz x + sz y + 2 > sz y`; A decoded gives `sz y < sz x < sz B` by `KY'`.
* disjunct 2 (`a2 C = op (a1 (a2 x)) B`) and disjunct 3 (`a2 C = op (a2 A) B`): the sub-case where
  that inner `op` is **free** is refutable by the same size argument; the sub-case where it
  **decodes** (so `a2 C = a1 (a1 B) = a1 x`) is **OPEN**. Extra facts available there: the inner
  decode's own CORE is `a2 x = op (a1 (a2 x)) (a1 x)` and its own `CK (a1 (a2 x)) A` — i.e. `A`, which

  and is where a contradiction should come from.

**(2)+(3) the two deep leaves of `CKlem (z y) : CK y (op z y)`** (lines ~292 and ~297). The theorem
is the closure statement "`op z y` is always recognised as a product with right argument `y`", and it
is proved by a two-level case split that closes everything except one cell:
* `op z y` free -> `Or.inl ⟨rfl, rfl⟩`.
* `op z y` decoded, `op z (a1 (a1 y))` **free** -> `a2 (a1 y) = J z (a1 (a1 y))`, so
  `a1 (a2 (a1 y)) = z` and CK's disjunct 2 fires. **Closed.**
* `op z y` decoded, `op z (a1 (a1 y))` decoded, `CK z (a2 y)` by **disjunct 1** -> `z = a2 (a2 y)`,
  CK's disjunct 3 fires. **Closed.**
* same, `CK z (a2 y)` by disjunct 2/3 with the inner `op k z` **free** -> `a2 y = J k z`, so
  `a2 (a2 y) = z` and disjunct 3 fires. **Closed** (this is the level I added last).

  Facts in context there: `hr : op z y = a1 (a1 y)`, `hgr : op z (a1 (a1 y)) = a1 (a1 (a1 (a1 y)))`,
  `hhr : op k z = a1 (a1 z)`, `q : a2 y = a1 (a1 z)`, and via `KY'`
  `sz z < sz (a1 (a1 y))` and `sz k < sz z`. **No size contradiction exists** (checked by hand: the
  inequalities are jointly satisfiable), so this needs either a structural invariant on decoded
  values (PLAYBOOK_PROOF §4's `Enc`/`RF` + fuel induction) or a fourth rule in the model.

### The mathematics behind the two holes — read this before adding rules

`op u v` must fire exactly when `a2 v = op z u` **for some z**, and that existential is what the whole
rule set approximates. The model can only test canonical keys. The closure argument above shows the
hierarchy is *almost* closed: every level's "free" branch supplies the canonical key, and only the
all-decoded spine escapes. Concretely:
* the existential is `Dec u := ∃z. op z u ≠ J z u`;
* `Dec u` = "the canonical key `a2 (a2 u)` decodes u" ∨ "the canonical key `a1 (a2 (a1 u))` decodes u"
  ∨ (a non-canonical spine that recurses upward on strictly LARGER terms);
* the upward recursion is why no finite rule set is obviously complete. Adding a 4th rule pushes the
  hole one level deeper; the extractor's 24 rules are exactly this hierarchy truncated at depth 4.

# THE THEOREM, STRENGTHENED — projections AND reconstructions

## (a) 11081's payload is never missing, so a reconstruction decode has nothing to reconstruct

## (b) A certification-by-recomputation branch was built, and it fails in the same cell

* **v16 — relax the mark on `a1 v` from `tg = 4` to `tg != 1`.** The `Adec` cell was never a payload

## FINAL STATEMENT

> **For `x = y * ((x * (y*x)) * (z*y))` over a free term algebra with total accessors, no rule set can
> be a model — whether its decode returns a projection of `v`, or a term reconstructed from `u`, `a1 v`
> and `a2 v`, or is certified by recomputation.**
>
> *Necessity.* Without a conjunct pinning `a2 v` to `u`, `D = op(B,C)` decodes: `z` is universally
> quantified and constrained by nothing, so `z := <free> q (op B q)` satisfies D's core exactly.
> Witness `x = y = g0`, `z = E(g0, E(F(g0,E(g0,g0)), g0))`, **size 9**.
>
> *Incompletability.* With it, the root must also fire when `C = op z y` decoded. Then
> `a2 v = a1 (a1 u)`, a proper subterm of `u`, so `a2 (a2 v)` can never be `u`: no branch of that kind
> stores its key, and the key sits at unbounded accessor depth (measured `y.11121`, depth 5, canonical
> paths at 2 and 3, one level deeper per nesting). Witnesses **size 59** and **size 15**. A branch that
> *recomputes* rather than reads (v17) does not escape: it is itself a decode that stores no key, and
> fails on the same size-15 witness.
>
> Verified across **seven carriers and nineteen rule sets**: free/`J` (24-rule extract, the inherited

## The escape is NOT a quotient — correcting the earlier pointer

An earlier note here pointed at `PLAYBOOK_QUOTIENT.md`. **That is wrong for this law and the next agent
should not spend time on it.** 11081's *semantic* free model is clean — `smallcheck.py 11081 9 1` gives
0 failures over 12,167 assignments (Addendum 0) — so the law forces **no identity**, and a quotient
carrier has nothing to quotient by. Every quotient design in that playbook starts from a derived
identity (`22591`'s `a = I3(a)`, the square collapses); 11081 supplies none.

What the impossibility actually indicts is the *free* term algebra: `x`, `y`, `z` range over all terms,
which is what hands the attacker `z` in the necessity half and an arbitrarily deep `y` in the
incompletability half. So the escape is a **different structure**, not a quotient of this one — a
carrier that is not freely generated, so that not every term is a legal value of `z`. Candidates worth
one look each, in order: a carrier with a well-formedness invariant carried by the constructors (so
`z := <free> q (op B q)` is not in the carrier at all); and the infinite non-term models of the
`hard2_0027` / ℚ-piecewise-linear playbooks, which are the only shipped Austin constructions that are
not term algebras.

# ADDENDUM 5 — the ANCHORED decode (12087's mechanism), and where it stops

Lab: `gen/_x11081_lab4.py`, drivers `gen/_x11081_run4.py` and `gen/_x11081_forceB2_l4.py`.

12087's finding — *a recomputation guard resists forgery by shape but not by a genuinely-satisfied
relation; what survives is a guard anchored by a conjunct only the model can produce* — is exactly why
v17 failed, and I wrote the reason without seeing it: **"the recomputation branch stores no key, so it
is itself the incompletability half."** An anchored branch stores one.

## The construction

Give the decode two results. `beta` is the law's own reading and returns the bare payload; `alpha`
fires where `beta` cannot and returns a node **carrying its own right argument**, so the next reader
sees an anchored `a2 v`:

```
beta  : core and (tg (a2 v) != 1 and a2 (a2 v) = u)          ->  a1 (a1 v)          -- bare
alpha : core and not beta-guard  (+ the two blocks below)    ->  D2 (a1 (a1 v)) v   -- tag 6, carries v
core  : tg v != 1 and tg (a1 v) != 1 and a2 (a1 v) = op u (a1 (a1 v))
```
Then when `C = op z y` fires alpha, `a2 v = D2 P y` at the root has `tg != 1` and `a2 (a2 v) = y = u`,
so **beta fires on it and returns the bare `x`** — the anchor works.

Two blocks on alpha, each of which I had already derived for another purpose and both of which are
load-bearing here (measured, not assumed):

| block | what it stops | effect on `forceD` |
| --- | --- | --- |
| none (v18) | — | **20,736 / 20,736** — alpha fires at D and the carrier collapses |
| `tg u != 4` (v19) | alpha at D (`u = B` is F-marked) | **0 / 20,736**, census `Ddec` FALSE everywhere |
| + Q-disjointness `not (tg v != 1 and a2 v = u)` (v20) | alpha at B (`a2 A = x = u`) | 0, and 220 fails -> 0 |

Note v19's `tg u != 4` is emphatically **not** a vacuous guard — it is the difference between total
collapse and a clean D. Contrast v8/v9 earlier, where an identical fail count proved the guard
certified nothing. *The fail count tells you which; the census tells you why.*

> The escape is a carrier whose **well-formedness invariant anchors every guard** — i.e. one in which

quotient by. The theorem indicts the **freeness**, not the equality.
