### ONESIDE is TRUE and is proved — the open leaf closed by fuel induction
The remaining leaf did NOT need a new idea beyond `PLAYBOOK_PROOF.md` §4: **the recursive case
hands `a2 x` both roles at once**, so the induction is on `sz x` and the step is immediate.
```lean
NEFREE {u v} (h : sz (op u v) < sz v) : op u v ≠ J u v
LFT {x w} (h : op x w ≠ J x w) :                       -- what a decoding pair says about its LEFT arg
    (tg (a1 x) = 2 ∧ a1 (a1 x) = a2 x ∧ a2 (a1 x) = a1 w)                        -- LSH  (R1/R2/R4)
  ∨ (op (a2 x) (a1 w) ≠ J (a2 x) (a1 w) ∧ tg (a1 w) = 2 ∧ a1 x = a1 (a1 w)
       ∧ sz (a1 x) < sz (a1 w))                                                  -- DSH  (R3, guard decoded)
RGT {u x} (h : op u x ≠ J u x) : tg x = 2 ∧             -- what it says about its RIGHT arg
    ( (tg (a2 x) = 2 ∧ a1 x = a1 (a2 x))                                                     -- a (R1/R3)
    ∨ (tg (a1 x) = 2 ∧ tg (a1 (a1 x)) = 2 ∧ a2 x = a2 (a1 (a1 x)) ∧ a1 (a1 (a1 x)) = a2 (a1 x))  -- b (R2)
    ∨ (tg (a1 x) = 2 ∧ a1 (a1 x) = op (a2 (a1 x)) (a2 x)) )                                  -- c (R4)
ONE (n : Nat) : ∀ x u w, sz x ≤ n → op u x ≠ J u x → op x w ≠ J x w → False
ONESIDE {u x w} (h1 : op u x ≠ J u x) (h2 : op x w ≠ J x w) : False := ONE (sz x) x u w (Nat.le_refl _) h1 h2
```
`LFT`'s **R3 branch is the whole trick**: split its guard `a1 x = op (a2 x) (a1 w)` with `TRs` —
the *free* half yields `a1 x = J (a2 x) (a1 w)`, i.e. LSH itself, so only the decoded half survives
and it carries `op (a2 x) (a1 w) ≠ J (a2 x) (a1 w)`, i.e. **`a2 x` is a LEFT argument**.
In the one recursive cell (RGT-c x LFT-DSH), `RGT`-c's guard `a1 (a1 x) = op (a2 (a1 x)) (a2 x)`
either is free (closed by size after one more `LFT`) or decodes, and then **`a2 x` is also a RIGHT
argument** — so `ih (a2 x) (a2 (a1 x)) (a1 w)` applies with `sz (a2 x) < sz x` from `tg x = 2`.
The other five combos are pure size arithmetic (`congrArg sz`, `sz_a2_lt`, `sz_a1`); `NOSELF` closes
(c, LSH).
