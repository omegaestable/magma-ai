## THE THREE REMAINING HOLES

```lean
theorem VF (x y z : M) : op (op (op y x) z) (op x z) = J (op (op y x) z) (op x z)
theorem BC (x y z : M) (hB : op (op y x) z ≠ J (op y x) z) : op x z = J x z
theorem AD {x y z : M} (hA : op y x ≠ J y x) (hC : op x z ≠ J x z) :
    op y (J (J (op y x) z) (op x z)) = x
```

* **`BC`** (N2 and N3 not both decoded). Sketch, all four sub-cases converge: `SH_of` applied to `(N1,z)`
  and to `(x,z)` both describe `a2 z`, as `J N2 w1` / `op N2 w1` and as `J N3 w2` / `op N3 w2`. In every
  combination one gets `N2 = N3` (by `Jinj`, or by `SZV` + a size contradiction when one side is an
  `op`, or by `INJ` when both are decoded). Then `op N1 z = op x z` with `op x z` decoded gives
  `N1 = x` by **`INJ`**, i.e. `op y x = x`, which `SZV` kills both ways (free: `sz x = sz y + sz x + 1`;
  decoded: `sz x < sz x`). The only fiddly part is the `(op, op)` combination when `w1 ≠ w2`
  (one side chain-form, the other third-product form).
* **`VF`** (V free). Partial size argument already available, and `BC` shortens it a lot:
  `V` decoded ⇒ `sz N2 < sz N3` (`SU`) and `sz V < sz N3` (`SZ`).
  - `N3` decoded ⇒ (by `BC`) `N2` free ⇒ `sz N2 = sz N1 + sz z + 1 > sz z > sz N3` ✗ **closed**.
  - `N3` free ⇒ `sz N3 = sz x + sz z + 1`; if `N2` free then `sz N1 < sz x`, so `N1` must be decoded
    (a free `N1` has `sz N1 = sz y + sz x + 1`) ✗ **closed for N1 free**.
    Open residue: `N3` free ∧ (`N1` decoded ∨ `N2` decoded). Attack with `SH_of (N2, N3)` where
    `N3 = J x z` is *known*, so `a1 N3 = x` and `a2 N3 = z` are readable and the two forms read
    `a1 x = J N2 V ∨ a1 x = op N2 V` with `z = J V (a2 x) ∨ z = op V (a2 x)`, or
    `a1 z = V ∧ x = op (op N2 V) (a2 z)`. Each gives a linear relation among
    `sz x, sz z, sz V, sz N2`; combined with `SZ`/`SU` on `N1`, `N2` this is an `omega` problem.
* **`AD`** is the expensive one and is the reason the byte cap binds (below). With `N1` and `N3` both
  decoded and `N2 = J N1 z` free, `x` is not readable from `V = J (J N1 z) N3`; the rules built for it
  are `P4`/`P5`/`P6`, and to *fire* one of them you must first learn `z`'s shape from
  `SH_of (x, z)` (`N3` decoded ⇒ `z` is an `x`-encoding) and then case on how free `z`'s own chain is —
  that trichotomy is exactly why the extractor needed rules 4, 5 and 6. Once a rule's guard
  `op X z = N3 = op x z` is established, **`INJ` gives `X = x`** and the result is `x`.

# THE OBSTRUCTION FOR 12087, STATED AND MEASURED ON BOTH HORNS

Law `x = y * (((y*x)*z) * (x*z))`; chain `N1 = y*x`, `N2 = N1*z`, `N3 = x*z`, `V = N2*N3`, root `y*V = x`.

**1. The root product must be a reading.** `op y V = x` for arbitrary `x`, and a free product or a tag is
structurally larger than its parts, so the root fires a rule returning a sub-expression of `(y,V)`.

**2. A reading must be anchored, or it forges.** A mark (`E u v`) commits to nothing, so a spurious firing
is harmless; a reading commits to an answer, so a spurious firing is a wrong value. The only anchor a term
model has is a constructor the model itself produces (`tg v = 3`): every other test is satisfiable by an
attacker-built term. **Measured**: `B0`'s guard is not a shape test but a genuinely-satisfied three-product
*relation*, and it still forged at the `N3` product — 945/4,000 — and adding a second certificate changed
the count by **zero**.

**3. So the anchor requires `op N2 N3 = E N2 N3`.**

**4. But `N2` can be opaque, and then no rule on `(N2,N3)` can certify the pair.** `op N1 z` is *forced* to
decode whenever `z` is itself a genuine encoding whose decoder is `N1` — take `z = enc(N1,p,q)`; the law
instance `(x:=p, y:=N1, z:=q)` demands `op N1 z = p`. `N2` is then an arbitrary carrier element carrying no
trace of `y`, `x` or `z`. The certificate that `(N2,N3)` is genuine is `N2 = op (op y x) z`, and
**`y` occurs in neither `N2` nor `N3`** — the pair simply does not contain the information. So the mark
must be shape-only.

**5. A shape-only mark is too broad.** **Measured** (v11): it changes `op` on pairs that the free cells
depend on and breaks them — 801/4,000, in two different cells.

**The dilemma, both horns measured:** mark narrowly ⇒ the opaque-`N2` cell is unmarked ⇒ the root's reading
is unanchored ⇒ it forges (945/4,000). Mark broadly ⇒ the free cells break (801/4,000).

This is not a formal impossibility theorem — law 11081's escape ("a carrier with a well-formedness
invariant, so the attacker's term is not in the carrier at all") is not ruled out here, and is the one
direction left. But it does say precisely why ten carrier iterations plus every finite extractor rule set
have failed, and it identifies the single missing ingredient: **a way to make `N2` carry its own provenance
without introducing a shape that fires broadly.**
