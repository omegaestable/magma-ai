### The proof that was ready, if a repaired model is ever found

The case tree above collapses to four rule lemmas whose guards are all `rfl`, plus freeness:

```
L_R2 : op z (J x (J z (J (op y x) y))) = x                       -- cells 1 and 2 (P2 + guard rfl)
L_R3 : E3 x → op z (J x (op z (op (op (a1 (a2 x)) x) (a1 (a2 x))))) = x   -- cells 3, 4
L_R4 : J y x = op z (op (op y x) y) → op z (J x (J y x)) = x      -- cell 5 (P4 rfl, guard = hyp)
```
with `E3 v := tg v = 2 ∧ tg (a2 v) = 2 ∧ tg (a2 (a2 v)) = 2 ∧ tg (a1 (a2 (a2 v))) = 2 ∧
a2 (a1 (a2 (a2 v))) = a1 v ∧ a1 (a1 (a2 (a2 v))) = a2 (a2 (a2 v))`, so **`P1 u v ↔ E3 v ∧ u = a1 (a2 v)`**
and **`P3 u v ↔ tg v = 2 ∧ E3 (a1 v)`** — worth keeping, it is what makes every guard `rfl`.

The freeness lemma that was going to carry it (proof sketched, fuel induction on `msr`, uses the
sibling agents' `mx`):

```
NOD : sz (a1 v) ≤ sz u + 1 → sz (a2 v) ≤ sz u → op u v = J u v
```
* R1/R2 die because they need `u = a1 (a2 v)`, so `sz u ≤ sz (a1 (a2 v)) < sz (a2 v) ≤ sz u`.
* Every R3/R4 guard is `a2 v = op u G` with a gate `msr u G < msr u v`.  Free branch:
  `sz (a2 v) = sz u + sz G + 1 > sz u` — contradiction.  Decoded branch: the IH applies at `(u,G)`
  because the two hypotheses are *preserved* (R3: `G = op (a1 (a1 v)) W`, both parts `< sz (a1 v)`;
  R4: `a2 v = J C A` forces `sz (op C A) ≤ sz (a2 v) ≤ sz u`), so `op u G` is free — contradiction.
`NOD` proves `op (J y x) y = J (J y x) y` (s2 free when s1 free) and `op x (J y x) = J x (J y x)`
(s4 free in cell 5, where R3-on-(z,s2) forces `x = J (a1 x) (J (J F y) F)` hence `sz y < sz x`).
It does **not** cover `op x (J z s2)` — which is exactly where the model turned out to be false.
